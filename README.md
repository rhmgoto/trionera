# トリオネラ

旧名: Market History Explorer / マーケット歴史探検

## 概要

過去の日経平均、NYダウ、ドル円の推移と、歴史イベント・政治イベント・災害・金融政策などを重ねて眺めるための個人用プロトタイプです。

イベントを選ぶと、イベント日前後の騰落率を表とグラフで確認できます。これは投資や経済史を楽しむためのアプリであり、売買判断を目的にしたものではありません。

## 起動方法

`index.html` をブラウザで開いてください。

Chart.js は CDN から読み込みます。グラフを表示するにはインターネット接続が必要です。外部バックエンドは不要で、登録イベントやCSVデータはブラウザの `localStorage` に保存されます。

## iPadで使う方法

おすすめは GitHub Pages で公開して、iPadのSafariやChromeから開く方法です。

1. GitHubで新しいリポジトリを作ります。
2. このフォルダの中身をリポジトリに保存します。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Deploy from a branch` を選び、`main` ブランチと `/root` を指定します。
5. 表示されたURLをiPadで開きます。
6. Safariの共有ボタンから `ホーム画面に追加` を選ぶと、アプリのように起動できます。

注意: イベントやCSVデータは、開いているブラウザの `localStorage` に保存されます。GitHub Pagesに保存されるわけではありません。iPadとPCで同じデータを共有したい場合は、イベントJSONの書き出しやCSVを使って移す運用になります。

## CSV形式

基本形式は以下です。

```csv
date,nikkei,dow,usdjpy,btc
1980-01-04,6560,824,237,
2014-09-17,15888.67,17156.85,107.58,457.33
```

- `date` は `YYYY-MM-DD` 形式です。
- `nikkei` は日経平均です。
- `dow` はNYダウです。
- `usdjpy` はドル円です。
- `btc` はビットコインの米ドル建て価格です。
- 空欄は欠損値として読み込み、エラーで停止しません。
- 列名が違う場合は、取込画面の簡易マッピング欄で列名を指定できます。

## 日次データCSV

`market-data-daily-1970.csv` は、1970-01-01から2026-05-29までを毎日1行にそろえたCSVです。

- 列形式は `date,nikkei,dow,usdjpy,btc` です。
- 土日祝や市場休場日は、直近で取得できた値を引き継いでいます。
- ドル円はFREDの都合で1971-01-04から値が入ります。1970年中のドル円は空欄です。
- ビットコインはYahoo Financeの `BTC-USD` で、2014-09-17から値が入ります。それ以前は空欄です。
- アプリの `データ取込` タブからCSVとして読み込めます。

## 主な機能

- サンプルデータのグラフ表示
- 年、月、表示期間の選択
- 実数値、指数化、前日比%、1か月、3か月、1年騰落率の切り替え
- イベントの登録、編集、削除
- イベント日前後の騰落率分析
- 複数イベント比較
- CSVインポート
- イベントJSONエクスポート
- iPadのタッチ操作を意識した大きめのUI

## 今後の拡張案

- Yahoo Finance、Stooq、FREDなどから取得したCSVの自動整形
- 月次・年次集計の専用ビュー
- イベントJSONインポート
- イベントごとの色分け強化
- 指標追加: TOPIX、S&P 500、米10年金利、原油、金など
- 分析メモのテンプレート化
- iCloud DriveやGoogle Driveとのファイル連携

## データ取得元候補

- 日経平均: Nikkei公式CSV、Yahoo Financeの `^N225`、Stooqの `^NKX` など
- NYダウ: Yahoo Financeの `^DJI`、Stooqの `^DJI` など
- ドル円: FREDの `DEXJPUS` など

## 注意

このアプリに表示される分析は、単純な騰落率計算です。歴史イベントとマーケット変動の因果関係を証明するものではありません。

実際の投資判断には使用しないでください。投資は自己責任です。
